How to use the hub

Work left to right: load data, check the analysis pages, then plan materials.

Pages

  • Data uploadLoad the M Plan, achievement, FG and normal inventory, the engineering master and the BOM & Master Voltex workbook. Files stay saved in this browser.
  • Plan vs achievementHow much of each item's plan is done and how much is still to produce.
  • Stock cover (DOS)Days of FG stock left at the planned rate, grouped by colour.
  • Out of stockRed items. Click one to see which components block production.
  • BOM lookupCheck any item and quantity against current stock.
  • Team dataWhen team sync is set up, the button in the top bar shows your connection. Files an editor uploads reach everyone's screen within seconds.
  • MRP plannerPaste the primary and Voltex shift plans to see combined component balances and shortages per day, then export to Excel. Tick Ignore Voltex Plan to run the primary plan alone.

Shortcuts

  • /Find an item code from any page
  • Ctrl + EnterRun the MRP check while typing in the shift plan
  • EnterRe-check an out-of-stock item after changing its required quantity
  • EscClose this window or the mobile menu
